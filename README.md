# Task 5 - Superstore Sales Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Superstore sales dataset to identify patterns, trends, relationships, and anomalies in business performance.

## Objective

To analyze sales, profit, quantity, discount, customer segments, product categories, regions, and time-based performance.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data understanding
- Data cleaning
- Statistical analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Outlier analysis
- Time-based analysis
- Product analysis

## Visualizations

- Histograms
- Boxplots
- Bar charts
- Scatterplots
- Pairplot
- Correlation heatmap
- Category analysis
- Region analysis
- Monthly sales and profit trends

## Key Findings

The analysis identified differences in sales and profitability across categories, regions, customer segments, products, and time periods. It also examined the relationship between discount and profit and identified potential outliers.
